Introdução ao HTML e estrutura básica

🟥
Módulo 1 — HTML: Estrutura. HTML (HyperText Markup Language) é a linguagem de marcação que define a estrutura de toda página web. Pense nele como o esqueleto de uma casa.

O que você vai aprender

  • O que é uma tag e como funciona
  • Estrutura obrigatória: <!DOCTYPE>, <html>, <head>, <body>
  • Diferença entre tags de abertura e fechamento
  • Atributos das tags (id, class, href, src)

Exemplo

index.html
<!-- Todo arquivo HTML começa assim -->
<!DOCTYPE html>
<html lang="pt-BR">

  <head>
    <!-- Metadados: não aparecem na tela -->
    <meta charset="UTF-8">
    <title>Minha Primeira Página</title>
  </head>

  <body>
    <!-- Tudo que aparece na tela fica aqui -->
    <h1>Olá, Mundo!</h1>
    <p>Minha primeira página web.</p>
  </body>

</html>
✓ No navegador:
Aba com o título “Minha Primeira Página”, um título grande “Olá, Mundo!” e o parágrafo abaixo dele.
💡
Dica: sempre salve o arquivo com extensão .html e abra no navegador para ver o resultado.

Textos, listas, links e imagens

O que você vai aprender

  • Títulos: <h1> ao <h6>
  • Parágrafo: <p>, negrito: <strong>, itálico: <em>
  • Listas ordenadas e não-ordenadas: <ol>, <ul>, <li>
  • Links: <a href="...">
  • Imagens: <img src="..." alt="...">

Exemplo

blog.html
<h1>Meu Blog</h1>
<h2>Receitas Favoritas</h2>

<p>Veja minhas <strong>receitas preferidas</strong> de 2024.</p>

<ul>
  <li>Bolo de chocolate</li>
  <li>Pizza caseira</li>
  <li>Pão de queijo</li>
</ul>

<!-- Link abrindo em nova aba -->
<a href="https://google.com" target="_blank">
  Visitar Google
</a>

<!-- Imagem com texto alternativo -->
<img src="foto.jpg" alt="Descrição da imagem" width="300">
💡
Dica: o atributo alt nas imagens é essencial para acessibilidade e SEO!

O que você vai aprender

Menu de navegação.

Conteúdo principal.

Artigo independente.

Rodapé.

Por que usar HTML semântico?

HTML semântico usa tags com significado, ajudando buscadores (Google) e leitores de tela a entender a página.

Exemplo

  <nav>
    <a href="#sobre">Sobre</a>

  <article>
    <h2>Meu Primeiro Post</h2>

  <p>© 2024 Meu Site</p>
</footer>

Tabelas e formulários

O que você vai aprender

  • Tabelas: <table>, <thead>, <tbody>, <tr>, <th>, <td>
  • Campos de formulário: <input>, <textarea>, <select>
  • Tipos de input: text, email, password, number, checkbox, radio
  • Atributo required para validação nativa

Exemplo

contato.html
<form action="/enviar" method="POST">

  <label for="nome">Seu nome:</label>
  <input type="text" id="nome" name="nome" required>

  <label for="email">E-mail:</label>
  <input type="email" id="email" name="email">

  <label for="msg">Mensagem:</label>
  <textarea id="msg" name="mensagem" rows="4"></textarea>

  <select name="assunto">
    <option value="duvida">Dúvida</option>
    <option value="sugestao">Sugestão</option>
  </select>

  <button type="submit">Enviar</button>
</form>
💡
Dica: sempre use <label for="id"> ligado ao id do input — melhora a acessibilidade!

Seletores, propriedades e Box Model

🟦
Módulo 2 — CSS: Estilo. CSS (Cascading Style Sheets) controla a aparência visual dos elementos HTML. O Box Model é o conceito mais importante: todo elemento é uma caixa.

O que você vai aprender

  • Formas de aplicar CSS: inline, <style>, arquivo externo .css
  • Seletores: tag, .classe, #id, combinadores
  • Box Model: margin → border → padding → conteúdo
  • Propriedades básicas: color, font-size, background, width, height

Exemplo

style.css
/* Seletor por tag */
h1 {
  color: #333;
  font-size: 2rem;
}

/* Seletor por classe */
.cartao {
  background: white;
  border: 1px solid #ddd;
  border-radius: 8px;

  /* Box Model */
  padding: 1rem;    /* espaço interno */
  margin: 1rem;     /* espaço externo */
  width: 300px;
}

/* Seletor por ID */
#titulo-principal {
  text-align: center;
  font-weight: bold;
}

/* Pseudo-classe: estado do hover */
button:hover {
  background: #0066cc;
  cursor: pointer;
}
💡
Dica: use box-sizing: border-box globalmente para o padding não aumentar o tamanho do elemento!

Flexbox: layout em linha e coluna

O que você vai aprender

  • display: flex — ativa o flexbox no container pai
  • justify-content — alinha no eixo horizontal
  • align-items — alinha no eixo vertical
  • flex-wrap — permite quebrar linha
  • gap — espaço entre os filhos

Valores de justify-content

Valor Efeito
flex-start Agrupa no início
flex-end Agrupa no fim
center Centraliza
space-between Espaço entre os itens
space-around Espaço ao redor

Exemplo

flexbox.css
/* Container pai */
.container {
  display: flex;
  justify-content: center;  /* horizontal */
  align-items: center;      /* vertical */
  gap: 1rem;
  flex-wrap: wrap;
  min-height: 100vh;
}

/* Centralizar um elemento na tela */
body {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

/* Navbar com espaço entre logo e links */
nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 1rem 2rem;
}
💡
Dica rápida: para centralizar qualquer coisa — display: flex; justify-content: center; align-items: center.

CSS Grid: layouts em grade

O que você vai aprender

  • display: grid
  • grid-template-columns e grid-template-rows
  • Unidade fr (fração)
  • grid-template-areas — nomear regiões
  • auto-fit e minmax para grades responsivas

Exemplo

grid.css
/* Grade de 3 colunas iguais */
.galeria {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}

/* Responsivo: 1 col no mobile, 3 no desktop */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 1.5rem;
}

/* Layout de página clássico */
.pagina {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 250px 1fr;
}

.pagina header { grid-area: header; }
.pagina aside  { grid-area: sidebar; }
.pagina main   { grid-area: main; }
.pagina footer { grid-area: footer; }
💡
Dica: repeat(auto-fit, minmax(250px, 1fr)) cria grades que se adaptam automaticamente ao tamanho da tela.

Responsividade e Media Queries

O que você vai aprender

  • Mobile-first: escrever CSS para celular primeiro
  • @media (min-width: ...) para adaptar ao tamanho da tela
  • Breakpoints comuns: 480px (mobile), 768px (tablet), 1024px (desktop)
  • Unidades relativas: %, rem, em, vw, vh

Exemplo

responsivo.css
/* Estilo padrão: mobile first */
.container {
  width: 100%;
  padding: 1rem;
}

.menu {
  display: none; /* esconde em celular */
}

/* Tablet: 768px ou mais */
@media (min-width: 768px) {
  .container {
    max-width: 720px;
    margin: 0 auto;
  }

  .menu {
    display: flex; /* aparece em tablet+ */
  }
}

/* Desktop: 1024px ou mais */
@media (min-width: 1024px) {
  .container {
    max-width: 960px;
  }

  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

Animações e transições CSS

O que você vai aprender

  • transition — suaviza mudanças de propriedade
  • @keyframes — define animações personalizadas
  • animation — aplica a animação ao elemento
  • Propriedades animáveis: opacity, transform, color, background

Exemplo

animacoes.css
/* Transição suave no hover */
.botao {
  background: #0066cc;
  transition: background 0.3s ease, transform 0.2s;
}

.botao:hover {
  background: #0044aa;
  transform: scale(1.05);
}

/* Animação de entrada */
@keyframes fadeIn {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.card {
  animation: fadeIn 0.5s ease forwards;
}

Variáveis, tipos e operadores

🟨
Módulo 3 — JavaScript: Interatividade. JavaScript é a linguagem de programação da web. Com ela, você adiciona comportamento e lógica às páginas.

O que você vai aprender

  • let — variável que pode mudar
  • const — valor que não muda
  • Tipos: string, number, boolean, array, object, null, undefined
  • Operadores: +, -, *, /, ===, !==, &&, ||, !

Exemplo

variaveis.js
// Variáveis
let nome = "Ana";
let idade = 25;
const PI = 3.14;
let ativo = true;

// Template literal (texto com variável)
let mensagem = `Olá, ${nome}! Você tem ${idade} anos.`;
console.log(mensagem); // "Olá, Ana! Você tem 25 anos."

// Array (lista)
let frutas = ["maçã", "banana", "laranja"];
console.log(frutas[0]); // "maçã"

// Objeto
let pessoa = {
  nome: "Carlos",
  idade: 30,
  cidade: "São Paulo"
};
console.log(pessoa.nome); // "Carlos"
✓ Console:
Olá, Ana! Você tem 25 anos.
maçã
Carlos
💡
Dica: prefira sempre const por padrão. Só use let quando precisar reatribuir o valor.

Funções, condicionais e loops

O que você vai aprender

  • Funções tradicionais e arrow functions
  • if / else if / else
  • switch
  • Loops: for, while, forEach, map, filter

Exemplo

funcoes.js
// Função tradicional
function somar(a, b) {
  return a + b;
}

// Arrow function (moderna)
const multiplicar = (a, b) => a * b;

console.log(somar(3, 4));        // 7
console.log(multiplicar(3, 4));  // 12

// Condicional
const nota = 7.5;

if (nota >= 7) {
  console.log("Aprovado!");
} else if (nota >= 5) {
  console.log("Recuperação");
} else {
  console.log("Reprovado");
}

// Loop com forEach
const frutas = ["maçã", "banana", "uva"];
frutas.forEach(fruta => {
  console.log(`Fruta: ${fruta}`);
});

// map: transforma array
const dobros = [1, 2, 3].map(n => n * 2);
// [2, 4, 6]

// filter: filtra array
const pares = [1, 2, 3, 4, 5].filter(n => n % 2 === 0);
// [2, 4]
✓ Console:
7
12
Aprovado!

DOM: manipulando a página com JS

O que você vai aprender

  • Selecionar elementos: querySelector, querySelectorAll
  • Alterar conteúdo: textContent, innerHTML
  • Alterar estilo: element.style, classList.add/remove/toggle
  • Criar e inserir elementos: createElement, appendChild
  • Ouvir eventos: addEventListener

Exemplo

dom.js
// Selecionar elementos
const titulo = document.querySelector("h1");
const botao = document.querySelector("#meu-btn");
const cards = document.querySelectorAll(".card");

// Alterar conteúdo e estilo
titulo.textContent = "Novo Título!";
titulo.style.color = "blue";
titulo.classList.add("destaque");

// Criar e inserir elementos
const novoItem = document.createElement("li");
novoItem.textContent = "Novo item da lista";
document.querySelector("ul").appendChild(novoItem);

// Responder a eventos
botao.addEventListener("click", () => {
  alert("Botão clicado!");
});

// Ler valor de um input
const input = document.querySelector("#campo-nome");
input.addEventListener("input", (e) => {
  console.log(`Digitando: ${e.target.value}`);
});
💡
Dica: querySelector retorna 1 elemento. querySelectorAll retorna uma lista de todos os elementos que batem com o seletor.

Fetch API: buscando dados da internet

O que você vai aprender

  • O que é uma API e JSON
  • fetch() para fazer requisições HTTP
  • async/await para lidar com operações assíncronas
  • Tratamento de erros com try/catch

Exemplo

fetch.js
// Buscar dados de uma API pública
async function buscarUsuario(id) {
  try {
    const resposta = await fetch(
      `https://jsonplaceholder.typicode.com/users/${id}`
    );

    if (!resposta.ok) throw new Error("Erro na requisição");

    const dados = await resposta.json();

    // Exibir na página
    document.querySelector("#nome").textContent = dados.name;
    document.querySelector("#email").textContent = dados.email;

  } catch (erro) {
    console.error("Falhou:", erro.message);
  }
}

buscarUsuario(1);
✓ Na página:
#nome → Leanne Graham
#email → Sincere@april.biz
💡
Dica: a API jsonplaceholder.typicode.com é gratuita e perfeita para praticar fetch sem precisar de backend.

LocalStorage e projeto final

O que você vai aprender

  • localStorage.setItem() e getItem() — salvar dados no navegador
  • JSON.stringify() e JSON.parse() — converter objetos para texto e vice-versa
  • Integrar HTML + CSS + JS em um projeto completo

Exemplo

storage.js
// Salvar dados
const usuario = { nome: "Ana", pontos: 150 };
localStorage.setItem("usuario", JSON.stringify(usuario));

// Recuperar dados
const salvo = localStorage.getItem("usuario");
const dados = JSON.parse(salvo);
console.log(dados.nome); // "Ana"

// Verificar se existe
if (localStorage.getItem("usuario")) {
  console.log("Usuário encontrado!");
}

// Deletar
localStorage.removeItem("usuario");
✓ Console:
Ana
Usuário encontrado!

Calculadora interativa

🟣
Projetos integradores. Aqui o conteúdo dos três módulos se junta em projetos de verdade.

Tecnologias: HTML + CSS (Grid) + JavaScript

O que praticar

  • Layout com CSS Grid para os botões
  • Eventos de clique
  • Lógica de construção de expressão matemática

Checklist

  • Display mostrando a expressão atual
  • Botões 0–9, operadores + - * /
  • Botão = para calcular
  • Botão C para limpar
  • Estilo com Grid responsivo

Código base

calculadora.html
<div class="calc">
  <div id="display">0</div>
  <div class="botoes">
    <button onclick="pressionar('7')">7</button>
    <button onclick="pressionar('8')">8</button>
    <button onclick="pressionar('9')">9</button>
    <button onclick="pressionar('+')">+</button>
    <!-- ... mais botões -->
    <button onclick="calcular()">=</button>
  </div>
</div>

<script>
  let expressao = "";

  function pressionar(val) {
    expressao += val;
    document.querySelector("#display").textContent = expressao;
  }

  function calcular() {
    expressao = String(eval(expressao));
    document.querySelector("#display").textContent = expressao;
  }
</script>
⚠️
Este código base usa eval() por simplicidade. Vale discutir com a turma por que ele é arriscado em aplicações reais e como substituí-lo por um parser de expressões.

Lista de tarefas (To-Do App)

Tecnologias: HTML + CSS + JavaScript + LocalStorage

O que praticar

  • Criar elementos dinamicamente com JS
  • Toggle de classes CSS
  • Persistência de dados com localStorage

Checklist

  • Input para digitar nova tarefa
  • Botão “Adicionar”
  • Clicar na tarefa para marcar como concluída
  • Botão para deletar cada tarefa
  • Dados salvos no localStorage (persistem ao recarregar)
  • Contador de tarefas pendentes

Código base

todo.js
function adicionarTarefa(texto) {
  const li = document.createElement("li");
  li.textContent = texto;

  // Clique para marcar como feita
  li.addEventListener("click", () => {
    li.classList.toggle("concluida");
    salvar();
  });

  // Botão de deletar
  const btn = document.createElement("button");
  btn.textContent = "✕";
  btn.addEventListener("click", (e) => {
    e.stopPropagation();
    li.remove();
    salvar();
  });

  li.appendChild(btn);
  document.querySelector("#lista").appendChild(li);
}

function salvar() {
  const itens = [...document.querySelectorAll("li")]
    .map(li => ({ texto: li.firstChild.textContent, feita: li.classList.contains("concluida") }));
  localStorage.setItem("tarefas", JSON.stringify(itens));
}
