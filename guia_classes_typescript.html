Classe

Em resumo: a classe é a "planta" de um objeto: descreve o que ele tem (atributos) e o que ele faz (métodos). Com new você cria objetos reais a partir dela, e cada um guarda seus próprios valores.

Quando usar: quando vários objetos têm a mesma estrutura (carros, alunos, produtos).

Classe Carromarca · modelo · ano
buzinar()
new
→
meuCarroToyota · Corolla
outroCarroHonda · Civic

A classe é escrita uma vez. Cada new cria um objeto independente, com a mesma estrutura e valores próprios: mudar a marca de um carro não afeta o outro.

Uma classe é um molde que define propriedades (atributos: características do objeto) e métodos (ações que o objeto pode realizar). Se o objeto é um carro específico, a classe é o projeto do carro.

class Carro {
  marca: string;   // atributo
  modelo: string;  // atributo
  ano: number;     // atributo

  buzinar() {      // método
    console.log('Biiii!');
  }
}

const meuCarro: Carro = new Carro();
meuCarro.marca = "Toyota";
meuCarro.modelo = "Corolla";

Construtor

Em resumo: roda sozinho no momento do new e já entrega o objeto pronto, com os valores iniciais. Sem ele, seria preciso preencher cada atributo depois de criar o objeto.

Quando usar: sempre que o objeto precisa de dados para existir (nome, idade, marca).

Passo a passo: (1) new Pessoa("Ana", 25) cria um objeto vazio; (2) o constructor é chamado com "Ana" e 25; (3) this.nome = nome copia o parâmetro para o atributo. O this é o próprio objeto que está sendo criado.

Método especial usado para inicializar objetos quando são criados. Em TypeScript/JavaScript usa a palavra reservada constructor.

  • É chamado automaticamente ao criar uma instância.
  • Pode receber parâmetros para inicializar os atributos.
  • Normalmente não retorna nada (retorna implicitamente o próprio objeto).
class Pessoa {
  nome: string;
  idade: number;

  constructor(nome: string, idade: number) {
    this.nome = nome;
    this.idade = idade;
  }
}

const pessoa1 = new Pessoa("Ana", 25);
const pessoa2 = new Pessoa("Joao", 40);

2.1 Atalho (opcional)

Um modificador antes do parâmetro cria e inicializa a propriedade automaticamente.

class Carro {
  constructor(
    public marca: string,
    public modelo: string,
    public velocidade: number = 0
  ) {}
}

Modificadores de acesso

Em resumo: controlam quem pode ver ou alterar cada membro da classe. É assim que se protege os dados (encapsulamento). Sem nenhum modificador, o membro é public.

Quando usar: deixe private o que é interno e abra apenas o necessário.

Erro comum: acessar um membro private de fora da classe (conta.saldo) gera erro de compilação. Crie um método público (como getSaldo()) para expor o dado de forma controlada.

Definem quem pode acessar os membros de uma classe (propriedades e métodos).

ModificadorAcessoQuando usar
publicEm qualquer lugarInterface pública da classe (padrão)
privateSomente dentro da classeDados internos que não devem ser expostos
protectedDentro da classe e subclassesDados que as filhas precisam acessar
readonlyLeitura em qualquer lugarValores que não devem mudar após a criação

readonly

Em resumo: o valor é definido uma vez (na declaração ou no construtor) e nunca mais muda. Tentar alterá-lo gera erro de compilação.

Quando usar: identificadores e dados fixos, como o id.

Permite que uma propriedade seja somente leitura.

class Produto {
  readonly id: number;
  constructor(id: number) {
    this.id = id;
  }
}

static

Em resumo: o membro pertence à classe, não ao objeto: existe uma única cópia, compartilhada por todos. Acesse com Classe.membro.

Quando usar: contadores, constantes e funções utilitárias que não dependem de um objeto específico.

Membros estáticos pertencem à classe em si, e não a cada instância. São acessados pelo nome da classe, sem criar um objeto.

class Contador {
  static total: number = 0;  // pertence à classe
  public nome: string;       // pertence à instância

  constructor(nome: string) {
    this.nome = nome;
    Contador.total++;
  }

  static resetar(): void {
    Contador.total = 0;
  }
}

const a = new Contador("Alice");
const b = new Contador("Bob");
console.log(Contador.total); // 2
console.log(a.nome);         // "Alice"

Herança

Em resumo: a classe filha aproveita tudo da classe pai e acrescenta ou muda apenas o que for diferente, evitando código repetido. Vale a relação "é um": um Carro é um Veículo.

Quando usar: quando a relação "é um" faz sentido. Se for "tem um", use um atributo.

Veiculomarca · velocidade
acelerar() · descrever()
▲ extends
Carro+ portas · buzinar()
Moto+ cilindradas

A seta aponta de quem herda para quem é herdado. Carro e Moto recebem tudo de Veiculo e declaram apenas o que é novo. Mudar algo em Veiculo vale para todas as filhas.

Uma classe filha (subclasse) herda propriedades e métodos de uma classe pai (superclasse). É a base do princípio "não repita a si mesmo". Use extends para herdar e super() para chamar o construtor do pai.

Analogia: um filho herda características do pai, mas pode ter as suas próprias ou modificar as herdadas.
class Veiculo {
  constructor(
    public marca: string,
    protected velocidade: number = 0
  ) {}

  acelerar(v: number): void {
    this.velocidade += v;
  }

  descrever(): string {
    return `${this.marca} a ${this.velocidade} km/h`;
  }
}

class Carro extends Veiculo {
  constructor(marca: string, public portas: number) {
    super(marca); // OBRIGATÓRIO: chama o construtor do pai
  }

  buzinar(): void {
    console.log("Biiiiip!");
  }
}

const carro = new Carro("Toyota", 4);
carro.acelerar(80);  // herdado do pai
carro.buzinar();     // próprio do Carro
console.log(carro.descrever()); // "Toyota a 80 km/h"

super()

Em resumo: super é o atalho para a classe pai. super(...) executa o construtor do pai; super.metodo() chama a versão do pai de um método.

Quando usar: no construtor da filha (obrigatório, antes do this) e para completar o método do pai em vez de substituí-lo.

Erro comum: usar this antes de chamar super() no construtor da filha. O objeto só é montado depois que o pai é construído, então o TypeScript bloqueia.

super é uma referência à classe pai. Use super() para chamar o constructor do pai e super.metodo() para chamar um método do pai dentro da filha.

Regra de ouro: se a classe filha tem um constructor, ela precisa chamar super() antes de usar this. Sem isso, o TypeScript dá erro de compilação.
class Veiculo {
  marca: string;
  ano: number;
  constructor(marca: string, ano: number) {
    this.marca = marca;
    this.ano = ano;
  }
  descrever(): string {
    return `${this.marca} (${this.ano})`;
  }
}

class Carro extends Veiculo {
  portas: number;
  constructor(marca: string, ano: number, portas: number) {
    super(marca, ano);   // chama o constructor do pai
    this.portas = portas; // só pode usar this DEPOIS do super()
  }
  descrever(): string {
    return super.descrever() + ` - ${this.portas} portas`;
  }
}

override

Em resumo: a filha troca um método herdado por uma versão própria. A palavra override declara essa intenção: se o método não existir no pai (por exemplo, erro de digitação), o compilador avisa.

Quando usar: sempre que reescrever um método do pai.

Quando uma subclasse reescreve um método que já existe na classe pai, isso se chama sobrescrita. A palavra-chave override torna a intenção explícita e protege contra erros: o compilador avisa se o método não existe no pai.

Analogia: você recebeu a receita de bolo da vó e usa override para mudar o recheio.
class Animal {
  falar(): string { return "..."; }
}

class Cachorro extends Animal {
  override falar(): string { return "Au!"; }
}

abstract

Em resumo: é uma classe incompleta de propósito. Define o que as filhas são obrigadas a ter (método abstrato) e pode trazer código já pronto. Não é possível usar new nela.

Quando usar: quando várias classes têm uma base comum, mas cada uma faz uma parte do seu jeito (ex.: calcularArea de cada forma).

«abstract» FormacalcularArea() → sem código
descrever() → já pronto
▲ extends
Circuloimplementa calcularArea()
Retanguloimplementa calcularArea()

A classe abstrata fixa a regra ("toda forma calcula sua área") e já entrega o que é comum (descrever). Cada filha completa a parte que é só dela. Se uma filha esquecer de implementar o método abstrato, o compilador dá erro.

Classes e métodos abstratos definem um contrato que as subclasses devem implementar. Não é possível criar instâncias diretas de uma classe abstrata: ela serve como molde.

Analogia: uma receita "abstrata" diz que você precisa de misturar() e assar(), mas não define como. Cada receita concreta implementa do seu jeito.
abstract class Forma {
  // Método abstrato: subclasses DEVEM implementar
  abstract calcularArea(): number;

  // Método concreto: herdado por todos
  descrever(): string {
    return `Área: ${this.calcularArea()}`;
  }
}

class Circulo extends Forma {
  constructor(private raio: number) { super(); }

  calcularArea(): number { // obrigatório!
    return Math.PI * this.raio ** 2;
  }
}

Interface

Em resumo: é uma lista do que um objeto precisa ter (propriedades e métodos), sem código. Quem implementa a interface é obrigado a cumprir a lista.

Quando usar: para descrever o formato de dados e para garantir que classes sem parentesco ofereçam os mesmos métodos.

«interface» Pessoaid · nome · saudar()
◀ implements
Aluno
Professor

A interface é só a lista de exigências. Aluno e Professor não precisam ter parentesco entre si: basta cumprirem o contrato.

Uma interface define o formato de um objeto ou classe: quais propriedades e métodos ele deve ter, sem implementar nada. Uma classe usa implements para assumir esse contrato e o compilador exige que todos os membros existam.

  • Existe só em tempo de compilação: não gera código JavaScript.
  • Propriedades opcionais usam ?, e também é possível usar readonly.
  • Uma classe pode implementar várias interfaces.
interface Pessoa {
  readonly id: number;
  nome: string;
  email?: string;      // opcional
  saudar(): string;
}

class Aluno implements Pessoa {
  constructor(public readonly id: number, public nome: string) {}

  saudar(): string {
    return `Olá, ${this.nome}!`;
  }
}

function apresentar(p: Pessoa): void {
  console.log(p.saudar());
}

apresentar(new Aluno(1, "Ana"));

Várias interfaces

interface Voador { voar(): void; }
interface Nadador { nadar(): void; }

class Pato implements Voador, Nadador {
  voar(): void { console.log("Voando"); }
  nadar(): void { console.log("Nadando"); }
}

Enum

Em resumo: dá nomes legíveis a um conjunto fixo de valores. Status.Ativo é mais claro e seguro do que usar o número 1 ou o texto "ativo" solto pelo código.

Quando usar: status, tipos e categorias com opções limitadas.

Por que não usar números soltos? Com status === 1 ninguém sabe o que o 1 significa. Com status === Status.Ativo o código se explica e o compilador impede valores inválidos.

Um enum é um conjunto de constantes nomeadas. Serve para representar valores fixos (status, direções, perfis) de forma legível e segura, no lugar de números ou textos soltos.

Enum numérico

Por padrão os valores começam em 0 e aumentam de 1 em 1.

enum Status {
  Pendente,   // 0
  Ativo,      // 1
  Cancelado   // 2
}

let s: Status = Status.Ativo;
console.log(s);          // 1
console.log(Status[1]);  // "Ativo"
Apenas enums numéricos permitem buscar o nome pelo valor (Status[1]).

Enum de strings

enum Direcao {
  Cima = "CIMA",
  Baixo = "BAIXO"
}

console.log(Direcao.Cima); // "CIMA"

Uso em classes

class Pedido {
  constructor(public status: Status = Status.Pendente) {}

  cancelar(): void {
    this.status = Status.Cancelado;
  }
}

Condicionais

Em resumo: fazem o programa tomar decisões: um trecho só executa se a condição for verdadeira.

Quando usar: if para decisões em geral; ternário para escolher entre dois valores em uma linha; switch para comparar uma variável com vários valores exatos.

nota ≥ 7 ?
sim →
Aprovado
não →
nota ≥ 5 ?
sim →
Recuperação
não →
Reprovado

As condições são testadas de cima para baixo e o primeiro caso verdadeiro vence. Por isso a ordem importa: teste o caso mais específico primeiro.

Controlam qual trecho do código será executado, de acordo com uma condição.

if / else if / else

const nota: number = 7;

if (nota >= 7) {
  console.log("Aprovado");
} else if (nota >= 5) {
  console.log("Recuperação");
} else {
  console.log("Reprovado");
}

If ternário

Forma curta de um if / else que devolve um valor: condição ? seVerdadeiro : seFalso.

const situacao = nota >= 7 ? "Aprovado" : "Reprovado";
console.log(situacao);

switch / case

Compara um valor com vários casos. Use break para encerrar cada caso e default para os demais valores.

const dia: number = 2;

switch (dia) {
  case 1:
    console.log("Domingo");
    break;
  case 2:
    console.log("Segunda");
    break;
  default:
    console.log("Outro dia");
}
Sem o break, a execução "cai" para o próximo case.

Operadores ?? e ?

Em resumo: dois atalhos para valores que podem não existir. ?? define um valor padrão; ?. evita erro ao acessar algo que pode estar ausente.

Quando usar: com dados opcionais ou vindos de fora, como API e formulários.

?? (coalescência nula)

Devolve o valor da direita somente se o da esquerda for null ou undefined. Diferente do ||, ele mantém valores como 0 e "".

const nome: string | null = null;
console.log(nome ?? "Sem nome");  // "Sem nome"

const qtd: number = 0;
console.log(qtd ?? 10);  // 0
console.log(qtd || 10);  // 10

?. (encadeamento opcional)

Acessa uma propriedade ou método apenas se o objeto existir. Se não existir, o resultado é undefined, sem erro.

interface Usuario {
  nome: string;
  endereco?: { cidade: string };
}

const u: Usuario = { nome: "Ana" };
console.log(u.endereco?.cidade);                // undefined
console.log(u.endereco?.cidade ?? "Não informada");

? em propriedades e parâmetros

O ? depois do nome marca o item como opcional.

function saudar(nome: string, titulo?: string): string {
  return titulo ? `${titulo} ${nome}` : nome;
}

Laços de repetição

Em resumo: repetem um trecho de código sem precisar escrevê-lo várias vezes.

Quando usar: for quando sabe quantas vezes repetir; for...of para percorrer uma lista; while para repetir até uma condição mudar; do while quando precisa executar ao menos uma vez.

condição ?
sim →
executa o bloco
↺ volta à condição
não →
sai do laço

O laço repete o ciclo "testa a condição → executa → volta" até a condição ficar falsa. Se nada dentro do bloco mudar a condição (como o n++), o laço nunca termina (laço infinito).

Repetem um bloco de código enquanto uma condição for verdadeira ou para cada item de uma coleção.

for

for (let i = 0; i < 5; i++) {
  console.log(i);  // 0, 1, 2, 3, 4
}

for...of

const frutas: string[] = ["maçã", "uva", "pera"];

for (const fruta of frutas) {
  console.log(fruta);
}

while

Testa a condição antes de cada repetição.

let n = 0;
while (n < 3) {
  console.log(n);
  n++;
}

do while

Testa a condição depois, então executa pelo menos uma vez.

let m = 10;
do {
  console.log(m);  // executa uma vez
  m++;
} while (m < 3);
break encerra o laço e continue pula para a próxima repetição.

forEach, map e filter

Em resumo: percorrem uma lista aplicando uma função a cada item. forEach apenas executa; map transforma; filter seleciona. map e filter não alteram o array original: devolvem um novo.

Quando usar: forEach para efeitos (exibir, salvar); map para criar uma lista transformada; filter para escolher itens.

[1, 2, 3, 4, 5, 6]
filter
n % 2 === 0
→
[2, 4, 6]
map
n × 10
→
[20, 40, 60]

Cada etapa recebe um array e devolve um novo, sem alterar o original. Isso permite encadear: primeiro selecione com filter, depois transforme com map.

Erro comum: usar map só para exibir itens. Se você não usa a lista devolvida, use forEach.

Métodos de array que percorrem os itens usando uma função (callback).

MétodoO que fazRetorno
forEachExecuta uma ação para cada itemvoid
mapTransforma cada itemNovo array do mesmo tamanho
filterMantém só os itens que passam no testeNovo array, igual ou menor
const numeros: number[] = [1, 2, 3, 4, 5, 6];

numeros.forEach((n) => console.log(n));

const dobro = numeros.map((n) => n * 2);
// [2, 4, 6, 8, 10, 12]

const pares = numeros.filter((n) => n % 2 === 0);
// [2, 4, 6]

// Encadeando
const resultado = numeros
  .filter((n) => n > 2)
  .map((n) => n * 10);
// [30, 40, 50, 60]
