Aprenda Java

Da sintaxe básica até interfaces — cada capítulo traz a explicação e um console para você ver o código rodando de verdade, na sequência que você precisa estudar primeiro.

O que é Java?

Java é uma linguagem orientada a objetos, fortemente tipada e compilada para uma máquina virtual — a JVM (Java Virtual Machine). O código-fonte não roda direto no sistema operacional: primeiro é compilado em bytecode, e a JVM interpreta esse bytecode em qualquer plataforma que a tenha instalada.

📝 .java

Código-fonte que você escreve, com extensão .java.

⚙️ javac

O compilador transforma o código em bytecode (.class).

☕ JVM

A máquina virtual executa o bytecode em qualquer sistema operacional.

💡
"Write once, run anywhere": o mesmo arquivo .class compilado no Windows roda sem alteração em Linux ou macOS, desde que haja uma JVM instalada.

Seu primeiro programa

Todo programa Java precisa de uma classe com um método main — é o ponto de entrada que a JVM procura para começar a execução.

Main.java
public class Main {
    public static void main(String[] args) {
        System.out.println("Olá, mundo!");
    }
}
✓ javac Main.java && java Main → Olá, mundo!

Variáveis e tipos de dados

Java é fortemente tipada: toda variável precisa de um tipo declarado, e esse tipo não muda depois. Os tipos se dividem em primitivos (valores simples, guardados diretamente) e referência (objetos, guardados como um endereço de memória).

TipoUso
intNúmeros inteiros de 32 bits. Ex.: int idade = 28;
longInteiros grandes de 64 bits. Ex.: long populacao = 8000000000L;
doubleNúmeros decimais de 64 bits. Ex.: double preco = 19.90;
booleanVerdadeiro ou falso. Ex.: boolean ativo = true;
charUm único caractere. Ex.: char letra = 'A';
StringTipo de referência para texto. Ex.: String nome = "Ana";
Variaveis.java
String nome = "Ana Silva";   // referência
int idade = 28;               // primitivo
double salario = 3500.50;
boolean ativo = true;

System.out.println(nome + " tem " + idade + " anos.");
✓ Ana Silva tem 28 anos.
💡
Desde o Java 10 existe var, que infere o tipo automaticamente: var idade = 28; continua sendo int por trás dos panos — só a escrita fica mais curta.

Operadores

Operadores combinam valores e variáveis para produzir um resultado — aritmético, comparativo ou lógico.

➕ Aritméticos

+ - * / % — soma, subtração, multiplicação, divisão e resto.

⚖️ Relacionais

== != > < — comparam dois valores e retornam boolean.

🔗 Lógicos

&& || ! — combinam condições booleanas.

✍️ Atribuição

= += -= *= — atribuem e atualizam valores.

Operadores.java
int a = 10, b = 3;

System.out.println(a % b);          // resto da divisão
System.out.println(a > b && b > 0); // AND lógico
System.out.println(a == 10);        // comparação
✓ 1 · true · true
⚠️
Não confunda = (atribuição) com == (comparação). Para comparar o conteúdo de objetos como String, use .equals() em vez de ==, que compara referências de memória.

Estruturas condicionais

Permitem que o programa tome decisões, executando blocos de código diferentes de acordo com uma condição.

Condicionais.java
int idade = 17;

if (idade >= 18) {
    System.out.println("Maior de idade");
} else if (idade >= 12) {
    System.out.println("Adolescente");
} else {
    System.out.println("Criança");
}
✓ Adolescente

switch

Útil quando há várias comparações do mesmo valor contra opções fixas.

Switch.java
int dia = 3;
String nome = switch (dia) {
    case 1 -> "Domingo";
    case 2 -> "Segunda";
    case 3 -> "Terça";
    default -> "Dia inválido";
};
System.out.println(nome);
✓ Terça

Estruturas de repetição

Repetem um bloco de código enquanto uma condição for verdadeira — evitam duplicar código manualmente.

for

Quando o número de repetições já é conhecido.

while

Quando a condição é testada antes de cada repetição.

do-while

Quando o bloco precisa rodar ao menos uma vez.

Repeticao.java
for (int i = 1; i <= 5; i++) {
    System.out.println("Contagem: " + i);
}

int contador = 0;
while (contador < 3) {
    System.out.println("while: " + contador);
    contador++;
}
✓ Contagem: 1…5 · while: 0, 1, 2

Arrays

Um array guarda vários valores do mesmo tipo em posições sequenciais, acessadas por índice — o primeiro elemento está sempre na posição 0.

Arrays.java
int[] notas = {8, 6, 9, 10, 7};

for (int i = 0; i < notas.length; i++) {
    System.out.println("Nota " + i + ": " + notas[i]);
}

// percorrendo com for-each
for (int nota : notas) {
    System.out.println(nota);
}
✓ Nota 0: 8 … Nota 4: 7
💡
O tamanho de um array é fixo depois de criado. Para uma coleção que cresce dinamicamente, Java oferece ArrayList, do pacote java.util.

Classes e objetos

Até aqui, tudo rodou dentro de um único método. A Orientação a Objetos organiza o código em torno de classes — moldes que descrevem características (atributos) e comportamentos (métodos) — e objetos, instâncias concretas criadas a partir desse molde.

🧩 Classe

O molde/planta. Ex.: a classe Carro descreve o que todo carro tem.

🚗 Objeto

Uma instância real. Ex.: meuCarro, criado a partir de Carro.

Carro.java
public class Carro {
    String modelo;
    int ano;
}

public class Main {
    public static void main(String[] args) {
        Carro meuCarro = new Carro();  // criando um objeto
        meuCarro.modelo = "Civic";
        meuCarro.ano = 2024;

        System.out.println(meuCarro.modelo + " - " + meuCarro.ano);
    }
}
✓ Civic - 2024
💡
Analogia: a classe é a planta de uma casa; o objeto é cada casa construída a partir dela. Você pode construir várias casas (objetos) diferentes a partir da mesma planta (classe).

Atributos

Atributos (ou campos) são as variáveis declaradas dentro de uma classe — representam o estado de cada objeto. Cada objeto tem sua própria cópia dos atributos.

Pessoa.java
public class Pessoa {
    private String nome;   // atributo
    private int idade;     // atributo

    public String getNome() { return nome; }
    public void setNome(String nome) { this.nome = nome; }
}
✓ classe "Pessoa" com 2 atributos privados

Encapsulamento

É boa prática declarar atributos como private, expondo o acesso apenas por métodos públicos (get/set) — isso protege o estado interno do objeto contra alterações indevidas de fora da classe. O capítulo 11 detalha todos os modificadores de acesso.

Métodos

Métodos são os comportamentos da classe — blocos de código que operam sobre os atributos do objeto. Recebem um nome, podem receber parâmetros e podem devolver um valor (ou void, quando não devolvem nada).

ContaBancaria.java
public class ContaBancaria {
    private double saldo;

    public void depositar(double valor) {   // método void
        saldo += valor;
    }

    public boolean sacar(double valor) {    // com retorno
        if (valor > saldo) return false;
        saldo -= valor;
        return true;
    }
}
✓ depositar() e sacar() alteram o estado interno de "saldo"
  1. Assinatura — tipo de retorno + nome + parâmetros.
  2. Parâmetros — valores recebidos entre parênteses.
  3. Corpo — lógica executada quando o método é chamado.
  4. Retorno — return devolve um valor ao chamador.

Construtores

Um construtor é um método especial, chamado automaticamente quando um objeto é criado com new. Serve para inicializar os atributos logo na criação do objeto. Tem o mesmo nome da classe e não tem tipo de retorno.

Pessoa.java
public class Pessoa {
    private String nome;
    private int idade;

    public Pessoa(String nome, int idade) {  // construtor
        this.nome = nome;
        this.idade = idade;
    }
}

// uso:
Pessoa p = new Pessoa("Ana", 28);
✓ objeto "p" já nasce com nome e idade preenchidos
💡
Se você não escrever nenhum construtor, Java gera um construtor padrão (sem parâmetros) automaticamente. Assim que você declara qualquer construtor próprio, esse padrão deixa de existir.

Modificadores de acesso

Modificadores de acesso controlam de onde uma classe, atributo, método ou construtor pode ser enxergado e usado. Eles são a base do encapsulamento: decidem o que fica exposto como "interface pública" e o que fica escondido como detalhe interno da classe.

ModificadorVisibilidade
privateSó dentro da própria classe. O nível mais restrito.
default (nenhum)Classe e qualquer outra classe do mesmo pacote — também chamado de package-private.
protectedClasse, mesmo pacote e subclasses (mesmo em outro pacote).
publicAcessível de qualquer lugar. O nível mais aberto.
ContaBancaria.java
public class ContaBancaria {
    private double saldo;              // só a própria classe acessa

    public ContaBancaria(double saldoInicial) {  // construtor público
        this.saldo = saldoInicial;
    }

    public double getSaldo() {         // método público — "porta de entrada"
        return saldo;
    }

    private boolean saldoSuficiente(double valor) {  // detalhe interno
        return valor <= saldo;
    }
}
✓ saldo e saldoSuficiente() ficam escondidos; getSaldo() e o construtor são a porta de entrada da classe

Onde cada modificador se aplica

Classes

Uma classe de nível mais alto só pode ser public ou default — nunca private ou protected.

Atributos, métodos e construtores

Podem usar os quatro níveis: private, default, protected ou public.

💡
Regra prática: comece restringindo tudo com private e só abra o acesso (protected ou public) quando outra classe realmente precisar usar aquilo. É mais fácil abrir depois do que fechar um acesso que já está sendo usado em vários lugares.
⚠️
protected só faz diferença real para herança: fora do pacote, apenas subclasses enxergam o membro. É por isso que atributos pensados para serem herdados — como o nome em Animal do próximo capítulo — costumam usar protected em vez de private.

Herança

Herança permite que uma classe (subclasse) reaproveite atributos e métodos de outra (superclasse), usando a palavra-chave extends. Representa uma relação "é um" — um Cachorro é um Animal.

Heranca.java
public class Animal {
    protected String nome;

    public Animal(String nome) { this.nome = nome; }

    public void emitirSom() {
        System.out.println(nome + " faz um som.");
    }
}

public class Cachorro extends Animal {   // herda de Animal
    public Cachorro(String nome) {
        super(nome);                     // construtor da superclasse
    }
}

Cachorro rex = new Cachorro("Rex");
rex.emitirSom();
✓ Rex faz um som.
💡
super(...) chama o construtor da superclasse; super.metodo() chama a versão do método definida na superclasse, mesmo que a subclasse a tenha sobrescrito.
⚠️
Java só permite herança simples de classes — uma classe só pode ter um extends. Para reaproveitar comportamento de várias fontes, use interfaces (capítulo 14).

Override (sobrescrita de métodos)

Override acontece quando uma subclasse redefine um método herdado da superclasse, dando a ele um comportamento próprio — mantendo a mesma assinatura (nome, parâmetros e tipo de retorno).

Override.java
public class Animal {
    public void emitirSom() {
        System.out.println("Som genérico de animal.");
    }
}

public class Gato extends Animal {
    @Override
    public void emitirSom() {          // sobrescreve
        System.out.println("Miau!");
    }
}
✓ Gato.emitirSom() substitui a versão de Animal

Override × Overload (sobrecarga)

OverrideOverload
Onde ocorreEntre superclasse e subclasseNa mesma classe
AssinaturaIdêntica à do método originalMesmo nome, parâmetros diferentes
ObjetivoMudar o comportamento herdadoOferecer variações do mesmo método
💡
A anotação @Override não é obrigatória, mas é boa prática: o compilador avisa se você errou a assinatura e acabou criando um método novo em vez de sobrescrever o existente.

Polimorfismo

Polimorfismo ("muitas formas") é a capacidade de tratar objetos de subclasses diferentes através de uma referência do tipo da superclasse — e cada um responder à mesma chamada de método com seu próprio comportamento, graças ao override.

Polimorfismo.java
Animal[] animais = {
    new Cachorro("Rex"),
    new Gato(),
};

for (Animal a : animais) {
    a.emitirSom();   // cada objeto executa a SUA versão
}
✓ Rex faz um som. · Miau!
💡
Analogia: um controle remoto "ligar" funciona para TV, ar-condicionado ou som — mesmo comando, comportamento diferente em cada aparelho. É exatamente isso que o polimorfismo faz com a.emitirSom().

Esse é o polimorfismo em tempo de execução: a JVM decide, ao rodar, qual versão sobrescrita do método chamar, com base no tipo real do objeto — não no tipo da variável.

Interfaces

Uma interface define um contrato: uma lista de métodos que qualquer classe que a implemente é obrigada a fornecer, sem impor como esses métodos são implementados. Diferente da herança, uma classe pode implementar várias interfaces.

Voador.java
public interface Voador {
    void voar();   // sem corpo — apenas o contrato
}

public class Passaro implements Voador {
    @Override
    public void voar() {
        System.out.println("O pássaro está voando.");
    }
}

public class Aviao implements Voador {
    @Override
    public void voar() {
        System.out.println("O avião decolou.");
    }
}
✓ Passaro e Aviao cumprem o contrato "Voador", cada um a sua maneira

Herança × Interface

Herança (extends)Interface (implements)
Quantas por classeApenas umaQuantas forem necessárias
O que compartilhaAtributos e implementaçãoApenas o contrato (assinaturas)
Relação típica"é um" (Cachorro é um Animal)"é capaz de" (Passaro é capaz de Voar)
💡
Interfaces dão o polimorfismo mais flexível em Java: um método pode receber um parâmetro do tipo Voador e funcionar com qualquer classe que implemente essa interface — Passaro, Aviao ou uma futura Drone.
⚠️
Desde o Java 8, interfaces podem ter métodos default com corpo, mas isso não muda sua função principal: definir um contrato que várias classes, não relacionadas por herança, podem cumprir.
